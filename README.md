# Titanic Dataset Exploratory Data Analysis

## Objective
Perform EDA to identify patterns, trends and relationships in Titanic dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Univariate Analysis
- Bivariate Analysis
- Correlation Analysis
- Outlier Detection

## Key Findings
- Females survived more than males.
- First class passengers had higher survival rates.
- Fare positively influenced survival.
- Age had limited impact.
